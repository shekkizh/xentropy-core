# Security

This is an early-stage local developer runtime. Run it only on workspaces and
real-service endpoints you have reviewed. Component context is sent to the
selected model during simulation. A contract or context file cannot widen the
fixed Codex tool policy, but real-service requests are made by the host process.

Report vulnerabilities through the repository's GitHub **Security → Report a
vulnerability** form. Include affected versions and a minimal reproduction;
do not include live credentials or private component context. Avoid posting
unpatched vulnerability details in public issues.
